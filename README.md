# Vyatsy Bot 🤖

Бот для колледжа ВятГУ (проект v1) с интеграцией искусственного интеллекта для поиска интересующего учебного сообщества из базы данных этих сообществ.

## 📁 Структура проекта

* `main.py` — основной файл запуска и логика работы бота.
* `ai_api.py` — модуль для взаимодействия с API искусственного интеллекта.
* `communities_db.py` — работа с базой данных сообществ и групп.

## 🚀 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd vyatsy_bot
   ```

2. **Создайте и активируйте виртуальное окружение (рекомендуется):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # для Linux/macOS
   venv\Scripts\activate     # для Windows
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
   *(Примечание: если файла `requirements.txt` еще нет, установите нужные библиотеки вручную, например `aiogram` или `pyTelegramBotAPI`).*

4. **Настройте переменные окружения:**
   Укажите токены для бота и API нейросети в настройках проекта или в файле `.env`.

5. **Запустите бота:**
   ```bash
   python main.py
   ```

## 🛠 Технологии

* **Язык:** Python 3
* **База данных:** встроенные структуры данных Python (`dict`)
* **AI API:** (GrokAI)
